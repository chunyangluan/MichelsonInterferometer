1. 原理描述

迈克尔逊干涉仪将同一束光分成两路，经两臂反射后重新叠加。若两束光在观察方向上的光程差满足相长或相消条件， 屏幕上会出现亮暗相间的干涉条纹。

等倾干涉中，干涉强度只与出射光线的倾角 θ 有关。观察屏上到中心距离相同的像素对应相同 θ， 因此形成以中心为圆心的同心圆环。

2. 物理公式与当前计算

角度映射： θ = atan(r / f), f = 200 mm

光程差： Δ = 2d cosθ

归一化强度： I = [1 + cos(2πΔ / λ)] / 2

3. 干涉实验物理模型

在本仿真中，画布中心代表 θ = 0 的观察方向；离中心越远，r 越大，θ = atan(r/f) 越大。 对同一半径上的所有像素，光程差 Δ 相同，因此显示为一圈亮暗相间的等倾干涉环。
